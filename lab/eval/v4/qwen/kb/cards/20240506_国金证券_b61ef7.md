# 全球资金回流中国能否持续?

## 核心观点

报告分析了全球宏观环境及国内政策对A股市场的影响，认为小盘成长风格有望持续。通过统计发现2024年前四个月北向资金净流入显著，且与美债利率走势背离，推断外资回流具有持续性。同时跟踪了行业轮动策略和选股因子的近期表现，给出了短期配置建议。

## 创新点

通过对比2023年与2024年前四个月北向资金流入与美债利率的关系，论证今年外资流入并非单纯由海外流动性驱动，而是基于中国市场自身强势，从而推断北向资金流入的持续性。同时提供了一套基于技术指标的行业轮动策略和基于IC分析的因子监控框架。

> 方法论价值：medium — 提供了行业轮动策略的近期表现数据和北向资金择时策略的实证结果，但缺乏对核心模型构建细节的深度披露，方法论参考价值中等。

## 方法步骤

1. 统计历史北向资金累计净流入量，并与往年同期及美债利率走势进行对比分析。
2. 构建滚动100日平均北向单日净买入成交额的分位点指标，观测北向资金情绪。
3. 基于北向资金分位点指标构建Wind全A指数的日频择时策略（高于2/3分位点持仓，否则空仓）。
4. 利用技术指标（VMAP, DMA, MACD等）构建行业轮动策略，并计算各指标在不同行业上的择时胜率。
5. 跟踪八大类选股因子（市值、成长、质量等）在主要指数成分股中的IC均值与多空收益。

## 核心公式

- 指标i在行业j上的择时胜率，分子为择时策略正收益之和，分母为不择时行业指数绝对收益之和。

  $$ WinRatio_{i, j} = \frac { \sum r_{i, j}, r_{i, j} > 0 } { \sum \left| R_{j} \right| } $$

## 关键结果

| 指标 | 数值 | 说明 |
|---|---|---|
| 北向资金年初至今净流入 | 742.44亿元 | 2024年前四个月 |
| 行业轮动策略年化收益率 | 11.67% | 截至2024年5月3日 |
| 北向择时策略超额收益 | 择时策略下跌0.9%，Wind全A指数下跌1.86% | 2024年以来 |
| 行业轮动策略上周平均收益 | 1.22% | 上期推荐行业 |

## 局限与注意

- 北向资金择时策略未考虑交易手续费（原文图表11注）。
- 行业轮动策略在2024年表现较差（收益率-4.22%），需警惕策略失效风险。
- 因子表现具有周期性，量价和低波因子在小盘股中表现好，但在大盘股中表现差，存在风格依赖。
- [推断] 择时胜率指标基于滚动60个交易日计算，可能存在滞后性。

## 可复现度：medium

提供了北向资金择时规则和行业轮动策略的部分指标（如VMAP, DMA），但行业轮动策略的具体技术指标构建细节和选股因子的具体计算公式仅在附录中给出了部分定义，复现完整策略需要进一步查阅该系列其他报告或假设标准因子构建方法。

## 原文依据

- 北向资金流入持续性的论证：「前四个月北向资金的净流入并不是因为海外流动性环境缓和带来的被动式流入,更多可能是中国市场自身的强势所带来的。」
- 行业轮动策略表现：「行业轮动策略的年化超额收益率为7.07%,信息比率为0.76。从分年度的表现可以看出,今年以来,行业轮动策略组合的收益率为-4.22%。」
- 因子风格分层现象：「量价和低波因子在中证500、中证1000和全A股票池中表现良好,但是在大市值的沪深300股票池中表现较差,说明资金在小盘股票池中的轮动现象明显,而大盘股中还是延续动量配置。」
- 微盘股风险预警：「在4月15日,偏体现市场交易情绪的波动率拥挤度指标重新上升到阈值之上,触发了波动率拥挤度风险预警信号」
