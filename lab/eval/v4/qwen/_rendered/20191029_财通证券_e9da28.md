# 似是而非:横截面回归还是时间序列回归?

## 核心观点

本文对比了以Fama-French模型为代表的时间序列回归和以Barra模型为代表的横截面回归在因子收益和暴露计算上的差异。实证表明，基于个股特征直接计算的因子暴露（横截面）在选股效果上优于基于时间序列回归得到的暴露。文章指出两种模型的R方分别代表解释力和预测力，不可直接比较，并强调时序剔除与横截面正交化的区别。

## 创新点

澄清了量化研究中常见的概念混淆：时间序列回归（Fama-French）与横截面回归（Barra）在参数设定（已知与待估）上的根本对立；指出了直接利用横截面个股特征作为因子暴露，在选股实证中优于通过时间序列回归估计的暴露系数；强调了R方在两种模型中分别对应“解释度”和“预测度”，数值差异源于研究目的不同而非模型优劣。

> 方法论价值：high — 深入辨析了资产定价中时间序列回归（Fama-French）与横截面回归（Barra）的核心差异，指出了因子暴露计算中时序回归与横截面特征的选股效果差异，并澄清了R方在解释与预测中的不同含义，对因子构建和检验方法论有重要指导意义。

## 方法步骤

1. 构建Fama-French三因子模型的时间序列回归：对个股过去252日收益率对日度因子收益回归，获取时序暴露系数。
2. 计算横截面因子暴露：直接使用个股特征（如自由流通市值、BP倒数）作为因子暴露。
3. 比较选股效果：计算两类暴露的Rank IC均值和T值，评估其在Wind全A指数中的选股能力。
4. 构建Double-Sort分组因子收益：按市值和BP分组构建SMB和HML因子收益，并与横截面回归得到的因子收益对比。
5. 进行滚动时间序列回归：对风格指数进行滚动回归，分析因子暴露的时变性及R方。
6. 分析特质动量因子的横截面相关性：检验在时序剔除市值和价值影响后，特质动量在横截面上与Size/BP的相关性。

## 核心公式

- Fama-French三因子时间序列回归模型，因子收益已知，暴露待估

  $$ $r_{i} - r_{f} = \alpha_{i} + \beta_{i} (r_{m} - r_{f}) + s_{i} SMB + h_{i} HML + \varepsilon_{i}$ $$

- Barra模型横截面回归，因子暴露已知，因子收益待估

  $$ $r_{n} = f_{c} + \sum_{s=1} X_{ns} f_{s} + \varepsilon_{n}$ $$

- SMB因子的Double-Sort分组构建公式

  $$ $\frac{(S/L+S/N+S/H)}{3} - \frac{(B/L+B/N+B/H)}{3}$ $$

## 关键结果

| 指标 | 数值 | 说明 |
|---|---|---|
| Size因子RankIC T值 | -3.00 | 横截面特征因子在Wind全A指数（2006.2.28-2019.9.27）中的选股效果 |
| BP因子RankIC T值 | 5.75 | 横截面特征因子在Wind全A指数中的选股效果 |
| 时序SMB系数RankIC T值 | 1.40 | 时序回归暴露因子在Wind全A指数中的选股效果 |
| 5x5组合回归R方均值 | 96% | Fama-French三因子对25个市值-BP组合的时间序列回归解释度 |
| 横截面回归R方 | 25% | Barra模型横截面回归对个股下期收益的解释度 |

## 局限与注意

- 实证区间为2006-2019年，可能受特定市场风格（如小市值因子2017年后回撤）影响。
- 横截面因子暴露直接使用个股特征，未考虑动态调整或更复杂的非线性关系。
- 时序回归暴露假设因子暴露稳定不变，这可能在实际中不成立。
- [推断] 未考虑交易成本和滑点对选股效果的实际影响。

## 可复现度：high

数据需求明确（日频行情、财务数据），方法为标准的时间序列回归和横截面回归，代码实现逻辑清晰，易于复现。

## 原文依据

- 时间序列回归与横截面回归在参数设定上的根本区别：「以 Fama-French 模型为代表的时间序列回归将因子收益视为已知、因子暴露视为待估计的参数;而在以 Barra 模型为代表的横截面回归中,将因子暴露视为已知、因子收益视为待估计的参数。」
- 横截面因子暴露选股效果优于时序回归暴露：「在选股能力方面,用个股特征得到的因子暴露具有更好的选股效果... 根据横截面上直接获取的个股特征因子值的选股效果均更为显著」
- R方在两种模型中含义不同：「Fama-French回归更加注重收益的解释,而Barra模型更加注重收益的预测,两种回归模型讨论的并不是同一个问题,因此不能直接将其 R 方进行比对。」
- 时序剔除与横截面正交化的区别：「在特质动量因子的计算中,我们在时间序列上剥离了市值和价值的影响之后,在横截面上个股与 Size 和 BP 仍然体现出强烈的相关关系。究其原因,我们认为时间序列上的剔除与横截面上的剥离是存在区别的,二者并不能完全等同。」
