# 行业的风格偏好:解析纯行业因子组合

## 核心观点

本文通过解析纯行业因子组合的性质，指出行业因子对股票收益的解释力虽强但稳定性差。研究发现银行与农林牧渔行业在Beta暴露相似但收益迥异，主要源于行业因子本身的贡献差异。报告强调在组合归因中不可忽视行业因子的独立贡献。

## 创新点

纯行业因子组合在风格因子上暴露为0，但在其他行业上并不为0，其收益本质上是做多该行业并做空市场因子的对冲组合收益。在收益归因中，行业因子与风格因子是正交分解的两个独立部分，不能仅通过风格暴露解释行业收益。

> 方法论价值：high — 详细推导了纯行业因子组合的数学性质，揭示了行业因子与风格因子在收益归因中的独立贡献，对构建多因子归因模型有重要参考价值。

## 方法步骤

1. 构建仅含行业因子的回归模型，通过约束条件（如市值加权平均为0）解决截距项与行业因子的完全共线性。
2. 引入风格因子，构建包含市场、行业、风格因子的全因子回归模型。
3. 采用加权最小二乘法（WLS）求解模型参数，权重为自由流通市值平方根。
4. 计算纯行业因子组合在各风格因子上的暴露度，验证其正交性。
5. 将行业指数收益拆解为市场因子、行业因子和风格因子三部分贡献。
6. 对比不同行业在风格暴露与纯行业收益上的差异，解释收益来源。

## 核心公式

- 仅包含行业因子的回归模型公式

  $$ $r _ { n } = f _ { c } ^ { S } + \sum _ { i } X _ { n i } f _ { i } ^ { S } + u _ { n } ^ { S }$ $$

- 行业因子收益的市值加权均值约束条件

  $$ $\sum _ { i } W _ { i } f _ { i } ^ { S } = 0$ $$

- 包含行业因子和风格因子的全因子回归模型

  $$ $r _ { n } = f _ { c } ^ { P } + \sum _ { i } X _ { n i } f _ { i } ^ { P } + \sum _ { s } X _ { n s } f _ { s } ^ { P } + u _ { n } ^ { P }$ $$

- 基于多因子模型的风险预测公式

  $$ $R i s k ( P ) = W ^ { \prime } V W = W ^ { \prime } ( X ^ { \prime } F X + \Delta ) W$ $$

## 局限与注意

- 行业因子夏普比率远低于风格因子，构建稳定的行业轮动策略难度大。
- 纯行业因子组合在其他行业上暴露不为0，无法做到完全正交。
- 收益归因基于历史数据，过去数据不代表未来，市场风格变化可能导致模型失效。
- [推断] 未考虑交易成本和冲击成本，纯行业因子组合可能涉及较高的换手率。

## 可复现度：high

报告提供了详细的回归模型公式、约束条件、权重设置及因子定义，数据需求明确，复现路径清晰。

## 原文依据

- 纯行业因子组合在风格因子上暴露为0，但在其他行业上并不为0：「对于纯行业因子组合而言,其在所有风格因子上的暴露仍然为0,但在其他行业因子上却并不完全等于0」
- 行业因子对股票收益的解释力强于风格因子：「绝大多数的行业因子都是非常显著的,t值显著度比例全部保持在50%以上,其均值水平达到74%」
- 行业因子夏普比率低，反映行业轮动策略构建难：「行业因子的t值显著度要远高于风格因子,然而其夏普比率却远低于风格因子,这在一定程度上反映了构建一个稳定的行业轮动策略之难」
- 银行与农林牧渔行业收益差异源于行业因子贡献：「银行业和农林牧渔行业在Beta上的暴露都非常低,但农林牧渔纯行业因子的收益非常之高,这是两个行业的实际收益相差明显的原因」
