# 你看到的不一定是你所想的:解密R方

## 核心观点

本报告指出，R²并非天然位于0到1，无截距项的线性拟合可能为负，是否加入截距项以及如何定义总平方和会显著改变结果。总R²关注股票总体波动，相对R²关注相对于市场均值的波动，两者不可混用；在一元线性回归中，R²等于IC的平方。报告还通过Barra多因子模型展示不同因子类别、回归权重和股票池对拟合优度的影响，并给出样本指数未来一个月的风险预测。

## 创新点

关键不是盲目追求更高的R²，而是先固定回归口径：依据经济含义决定是否过原点，明确使用总R²还是相对R²以及采用何种回归权重；单因子时可用IC²进行一致性核验，多因子模型则应结合调整R²、增量解释能力和样本外风险预测，避免把统计口径变化或过拟合误判为模型改进。

> 方法论价值：medium — 报告给出了截距项、总/相对R²、调整R²与IC²之间可操作的口径和实证比较，适合改进多因子模型评估，但方法主体为标准计量工具且完整实现依赖前序报告。

## 方法步骤

1. 明确因变量为个股收益、解释变量为国家、行业和风格因子，并根据经济含义判断是否满足过原点条件，进而决定是否加入截距项。
2. 按报告附录构造风格暴露，对波动率、流动性或待挖掘Alpha实施所要求的正交化或中性化处理。
3. 根据异方差性选择普通最小二乘、市值平方根加权或市值加权回归，计算个股残差收益。
4. 按回归是否包含截距项，分别计算标准R²或过原点R²，并使用自由度调整后的R²惩罚新增解释变量。
5. 在Barra收益模型中分别计算总R²与相对R²，按国家、行业、风格因子类别比较增量解释能力。
6. 在一元线性回归中将R²与IC平方进行一致性核验，同时检查样本量、权重集中度及异常收益拟合是否抬高R²。
7. 稳健估计共同风险矩阵和特质风险矩阵，结合指数成分权重预测组合风险，并检查缺失因子股票的数量及权重覆盖率。

## 核心公式

- 含截距项线性回归的标准判定系数，表示样本总波动中可由解释变量解释的比例。

  $$ R ^ { 2 } \equiv \frac { S S E } { S S T } = 1 - \frac { S S R } { S S T } $$

- 过原点回归的R²，分母使用未 demean 的因变量平方和，因而可能出现负值。

  $$ R ^ { 2 } = 1 - \frac { \mathit { S S R } } { \mathit { S S T } ^ { o r i g i n } } = 1 - \frac { \sum _ { i = 1 } ^ { N } ( y _ { i } - \hat { y } _ { i } ) ^ { 2 } } { \sum _ { i = 1 } ^ { N } y _ { i } ^ { 2 } } $$

- 调整R²，对解释变量个数进行自由度惩罚；新增因子解释力不足时，调整R²会下降。

  $$ \bar { R } ^ { 2 } = 1 - \frac { \mathit { S S R } / ( n - k ) } { \mathit { S S T } / ( n - 1 ) } $$

- Barra总R²，以未去均值的股票收益总波动为分母，反映因子对总体波动的解释比例。

  $$ R _ { T } ^ { 2 } = 1 - \frac { \sum _ { n } w _ { n } u _ { n } ^ { 2 } } { \sum _ { n } w _ { n } r _ { n } ^ { 2 } } $$

- Barra相对R²，以股票相对于全样本加权平均收益的波动为分母，更贴近主动投资中的相对收益解释能力。

  $$ R _ { R } ^ { 2 } = 1 - \frac { \sum _ { n } w _ { n } u _ { n } ^ { 2 } } { \sum _ { n } w _ { n } ( r _ { n } - \bar { r } ) ^ { 2 } } $$

## 局限与注意

- [原文] 解释因子越多时R²通常越大，若将R²作为唯一评价标准会导致严重过拟合，应同时报告调整R²。
- [原文] 样本内解释能力与样本外风险预测虽有一定正相关，但相关程度远弱于直觉；缩小样本、提高少数股票权重以及拟合异常收益均可能人为抬高R²。
- [原文] 总R²会受到市场系统性波动影响，在剧烈波动时期明显增加，跨市场状态直接比较可能失真。
- [原文] 停牌股票或大类因子值缺失的股票会被剔除；若缺失股票数量或权重占比过高，收益归因和风险预测会受到较大影响。
- [原文] 历史风格可能变化，模型存在因市场风格改变而失效的风险。
- [推断] R²=IC²不能机械推广到多因子、非线性、无截距或非普通IC口径；加权情形还需明确IC与R²采用一致的权重。

## 原文依据

- 不含截距项时R²可能为负。：「R2并非总是大于 0 而小于 1,在不加截距项的回归中,R<sup>2</sup>可能出现负值。」
- 缺乏过原点依据时应统一加入截距项。：「当没有足够的信息显示数据穿过原点时,财通金工建议统一在模型中加上截距项。」
- 总R²与相对R²的分母含义不同。：「总R2和相对R2仅在于计算方法不同,前者关注股票的总体波动,后者关注股票相对于市场均值的波动」
- 一元线性回归中R²等于IC平方。：「在一元线性回归中,R2等同于自变量与因变量相关系数的平方。在单因子测试中,R<sup>2</sup>即为 IC 的平方。」
