# 基于混沌理论的股指期货噪声趋势交易(NTT)策略

## 核心观点

报告基于混沌理论的相空间重构与粗糙熵，通过Levenberg-Marquardt非线性拟合估计股指期货高频价格中的噪声标准差，并用噪声占比NTS刻画市场随机性。当上午NTS较小且呈单边走势时，午后顺势建仓并于收盘前平仓，构成NTT策略。一年样本内加入噪声条件后，成功率、收益率与夏普比率均优于无噪声条件的普通趋势交易。

## 创新点

把混沌理论中的噪声环境粗糙熵拟合方法引入高频价格，用噪声占比NTS作为趋势交易的过滤条件：噪声小意味着人为主导、趋势延续概率大，噪声大则以随机游走为主应回避。由于日间NTS波动剧烈，只在上午NTS推断下午走势，利用午休间隔短、噪声状态相对稳定的假设。

> 方法论价值：medium — 提出基于混沌理论粗糙熵估计噪声比例并用于日内趋势过滤的新思路，方法有原创性，但样本仅一年、阈值在样本内选取、未计交易成本，稳健性不足。

## 方法步骤

1. 提取股指期货当月连续合约30秒高频数据，取每日10:00至11:30共180个数据点，剔除开盘初期剧烈震荡段
2. 对序列做相空间重构（时滞τ=1，嵌入维n=180），计算RP图及关联熵K，并加入修正系数β=1/√π
3. 假设噪声服从高斯分布，构造含噪声的粗糙熵表达式，以阈值ε为自变量，用LM非线性拟合得到噪声标准差σ_noisy
4. 计算NTS=σ_noisy/σ_data，作为上午噪声占比
5. 判定上午是否单边走势：方法一为4阶多项式拟合并检验极值，方法二为11:30与10:00价差的绝对值dif是否超过阈值
6. 若NTS<10%且上午为单边走势，则午后开盘顺势做多或做空（5倍杠杆），15:00前平仓；否则不交易
7. 扫描dif阈值，观察收益率平台结构（0.011-0.017），并与取消噪声条件的普通趋势交易对比

## 核心公式

- 噪声标准差与原始序列标准差之比，表示时间序列中噪声所占比例

  $$ NTS = \frac{\sigma_{noisy}}{\sigma_{data}} \in [0, 1] $$

- 由平均嵌入维<n>估算关联熵K

  $$ K \approx \ln \frac{<n>-1}{<n>-2} $$

- 递归图(RP图)的二元函数，H为Heaviside阶跃函数

  $$ P ( i , j ) = H ( \varepsilon - \left\| \vec { y } _ { i } - \vec { y } _ { j } \right\| ) $$

- Levenberg-Marquardt迭代步长，用于非线性拟合粗糙熵方程

  $$ \delta _ { k } = ( J _ { k } ^ { T } J _ { k } + \lambda _ { k } I ) ^ { - 1 } J _ { k } ^ { T } \varepsilon _ { k } $$

## 局限与注意

- 样本仅为股指期货上市后一年（2010.4-2011.4），原文也承认历史样本偏少，实际效果需进一步确认
- dif阈值与平台区间、NTS阈值10%、4阶多项式均在同一样本内选取，[推断]存在较严重的样本内过拟合，无样本外检验
- 未计交易成本（原文因交易次数少而略去），[推断]5倍杠杆下滑点与手续费、保证金风险会显著影响结果
- NTS逐日剧烈震荡，只能用于日内（上午推断下午），无法用于隔日择时，也无法用于高频交易
- [推断]相空间重构与LM拟合依赖嵌入维、时滞、β、p等设定，且文中对噪声高斯假设与均匀分布假设较粗略，拟合稳定性未做检验
- [推断]噪声小等同于人为操纵这一解释缺乏直接证据，且表2中dif较高时普通趋势交易接近甚至超过NTT（如0.015-0.016），噪声条件优势并非处处成立
- [推断]累积收益率为简单累加口径且按5倍杠杆，年化夏普的计算方式原文未详细说明

## 可复现度：medium

交易规则、阈值与参数（n=180、τ=1、β=1/√π、NTS<10%）给得较清楚，但粗糙熵的数值实现（ε扫描范围、拟合初值、p取值等）和平仓细节不完整，且数据为付费高频源。

## 原文依据

- 核心思想：噪声小代表人为主导、趋势更可能延续，据此在趋势交易中加入噪声判据：「当噪声较大时,价格的随机性较强;而噪声较小时,则有可能存在较大程度上的人为操作成分」
- 噪声估计方法：以粗糙熵为阈值ε的函数，用非线性拟合求噪声标准差：「通过(20)式进行非线性拟合,并得到参数a ,b ,c ,κ 和 $\sigma$ ,其中 $\sigma$ 就是我们希望得到的时间序列中噪声的标准差」
- 策略设计：因日间NTS剧烈波动，仅用上午噪声判断午后趋势并在收盘前平仓：「如果上午的 NTS 值较小,且盘面出现单边走势,则午后有较大概率延续单边走势」
- NTS日间震荡剧烈，不适用于隔日择时：「该指标震荡非常剧烈,因此不适用于隔日择时」
