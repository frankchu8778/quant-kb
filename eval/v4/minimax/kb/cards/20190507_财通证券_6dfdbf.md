# 多因子风险预测:从怎么做到为什么

## 核心观点

报告将多因子协方差估计拆分为共同风险和特质风险，并解释EWMA、Newey-West、特征值调整、结构化填充与贝叶斯收缩背后的逻辑。偏差统计量用于检验样本外风险预测，正态假设下完美预测对应B=1，但金融收益的尖峰厚尾会降低95%置信区间的覆盖率，因此不能要求偏差统计量必须等于1。利用稳健风险矩阵与指数权重，可以进一步预测指数未来一个月的风险。

## 创新点

风险模型改进的关键不是孤立地替换某个协方差估计器，而是把共同风险与特质风险中的偏差来源逐层拆解和纠偏，并以样本外偏差统计量闭环验证；在尖峰厚尾分布下，评价风险预测应关注置信区间覆盖概率，而非B是否恰好等于1。

> 方法论价值：high — 报告系统给出共同风险与特质风险协方差的多阶段纠偏流程、偏差统计量及蒙特卡洛验证，可直接用于多因子风险模型复现。

## 方法步骤

1. 准备个股日频收益、交易状态、市值、风格因子、财务基础数据及指数成分股权重，并剔除无法满足模型输入要求的股票。
2. 按附录定义估计股票的风格因子暴露、因子收益和特质收益；因子收益可由股票收益对因子暴露进行横截面回归得到。
3. 对共同因子收益计算EWMA协方差矩阵，近期数据赋予更高权重，样本均值也采用指数加权以保证矩阵半正定。
4. 使用Newey-West调整处理日度收益自相关，并按21个交易日尺度缩放月度风险矩阵。
5. 对协方差矩阵进行特征值分解，通过蒙特卡洛生成正交特征组合收益，计算各特征组合的实际风险与预测风险之比，并据此放大或缩小对应特征值。
6. 由历史特质收益估计特质风险，使用完整度和异常值指标计算数据质量参数γ；对低质量股票从高质量相似股票池进行结构化填充。
7. 将个股特质风险向其市值分组的市值加权平均风险压缩，依据个股偏离程度确定压缩密度，并选择压缩系数q。
8. 以偏差统计量开展滚动样本外检验，例如用过去252日滚动波动率预测下一日风险；同时以指数成分权重聚合风险，并用Risk(P)=W'VW=W'(X'FX+Δ)W预测指数风险。

## 核心公式

- 样本协方差下最优投资组合真实波动与预测波动的关系，N为股票数量、T为样本观测数量。

  $$ \sigma _ { t r u e } \approx \frac { \sigma _ { e s t } } { 1 - ( N / T ) } $$

- 偏差统计量；B大于1表示风险被低估，B小于1表示风险被高估。

  $$ B = \sqrt { \frac { 1 } { T - 1 } \sum _ { t = 1 } ^ { T } \bigl ( b _ { t } - \bar { b } _ { t } \bigr ) ^ { 2 } } . $$

- 共同风险矩阵的指数移动加权平均估计。

  $$ F _ { k l } ^ { E W M A } = \sum _ { s = t - h } ^ { t } \lambda ^ { t - s } \big ( r _ { k , s } - \bar { r } _ { k } \big ) \big ( r _ { l , s } - \bar { r } _ { l } \big ) / \sum _ { s = t - h } ^ { t } \lambda ^ { t - s } $$

- Newey-West自相关调整，并将日频协方差缩放至21日尺度。

  $$ F ^ { N W } = 2 1 \times \left( F ^ { E W M A } + \sum _ { \Delta = 1 } ^ { D } \left( 1 - \frac { \Delta } { D + 1 } \right ) \left( C _ { + \Delta } ^ { ( d ) } + C _ { - \Delta } ^ { ( d ) } \right) \right) $$

- 蒙特卡洛模拟得到的第k个特征组合风险缩放系数。

  $$ \lambda ( k ) = \sqrt { \frac { 1 } { M } { \sum _ { m = 1 } ^ { M } \frac { \widetilde { D } _ { m } ( k ) } { D _ { m } ( k ) } } } . $$

## 关键结果

| 指标 | 数值 | 说明 |
|---|---|---|
| 样本协方差矩阵估计运算次数 | N(N+1)/2 | N为股票数量；多因子方法以K个因子替代N只股票，其中K远小于N |
| 样本协方差导致的最优组合风险低估 | 估计风险为真实风险的1/2 | 用100个交易日估计50只股票的收益率协方差矩阵 |
| 偏差统计量95%置信区间近似式 | [1−√(2/T), 1+√(2/T)] | 收益率正态分布假设下；T指回测区间内样本外收益序列长度，而非波动率估计的回望长度 |
| 厚尾分布下偏差统计量落入95%区间的平均概率 | 峰度k=5时约87%；峰度k=10时约80% | 正态分布峰度k=3时基本约为95%；每个T进行1000次蒙特卡洛模拟 |

## 局限与注意

- 原文风险提示：本报告统计结果基于历史数据，过去数据不代表未来，市场风格变化可能导致模型失效。
- 收益归因和风险预测会剔除暂停上市或大类因子值缺失的股票；原文提示，缺失股票数量过多或权重占比过大会明显影响结果，样本指数纳入比例均在92%以上。
- 特征值调整的完整操作需参阅“星火”系列（二），本报告主要解释原理，复现时仍需补齐参数与实现细节。
- [推断] 特征值调整的蒙特卡洛模拟采用正态分布设定，而真实收益存在尖峰厚尾，可能使模拟风险偏差与实际偏差不同。
- [推断] 贝叶斯压缩依赖特质风险与市值的强相关关系及市值分组，q为经验赋值；市场结构变化时需要重新校准。
- [推断] 最优组合权重仍同时依赖期望超额收益的一阶估计；报告主要处理协方差矩阵对应的二阶风险，未展示包含交易成本的策略回测。

## 原文依据

- 结构化协方差估计将风险拆分为共同风险与特质风险，并进行多阶段调整。：「基于结构化的协方差矩阵估计方法将股票收益协方差矩阵拆解为共同风险矩阵和特异风险矩阵两个部分,并对两个矩阵的估计进行了多步调整。」
- 尖峰厚尾分布下，不应要求偏差统计量严格等于1或完全落入正态假设下的置信区间。：「由于现实金融数据并不服从正态分布,我们应该允许计算得到的偏差统计量与 95%置信区间存在一定的偏离,而不能对其结果过于苛求。」
- 特征值调整根据模拟风险偏差对不同特征组合分别放大或缩小风险。：「通过对低估组合的风险进行适当放大、对高估组合的风险进行适当缩小,即可得到更为准确的协方差矩阵。」
- 特质风险的贝叶斯收缩以市值分组均值为先验风险。：「其主要思想是将单只股票的特异风险向其所在的市值分组的市值加权平均风险压缩」
