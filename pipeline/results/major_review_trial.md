# 檢查員判的 critical / major：人工複核表

每一條對照原文判斷：**真**（卡片確實錯）、**誤報**（卡片沒錯）、**吹毛求疵**（不算錯但可改）。
「引文」是檢查員自己附的原文證據；「引文在全文」是程式比對的結果，找不到的優先懷疑是誤報。

## 1. 20190324_财通证券_53adb9 / deepseek 寫的卡

- 嚴重度 / 類型：**major** / 引用不支持（整張卡判 revise）
- 欄位：`method_steps[7]（第 8 步：比較三種方法的填充效果）`
- 卡片寫：比較三種方法的填充效果：逐因子計算填充值與實際值相關係數，結構化法在財務因子與價量因子上均最高，行業均值次之，市值分組均值最差。
- 檢查員說原文是：原文只斷言結構化法最優，並明確說行業均值與市值分組均值「對於不同的數據有不同的適用程度」，並未給出「行業均值次之、市值分組均值最差」的排序。原文表 2 中市值分組均值在盈利（49.61% vs 34.89%）、成長（13.80% vs 7.22%）、槓桿率（61.52% vs 34.56%）、BP（44.13% vs 37.77%）、波動率（27.48% vs 9.33%）、動量（44.81% vs 28.30%）共 6 個因子上都高於行業均值；只有 Beta、流動性兩個因子是行業均值較好。此排序與表 2 數字及卡片自身 key_results（盈利 49.61% > 34.89%）互相矛盾，會讓借用者在備選方案上選錯。
- 引文：「总体来讲结构化方法的相关系数都要更高,而行业均值填充和市值分组均值填充对于不同的数据有不同的适用程度。」（1.3 实证检验）
- 引文在全文：找得到
- 人工判定：＿＿（真 / 誤報 / 吹毛求疵）

## 2. 20190619_财通证券_3bd8a5 / opus 寫的卡

- 嚴重度 / 類型：**major** / 方法对象错误（整張卡判 revise）
- 欄位：`core_idea`
- 卡片寫：「要判断真实的升贴水和期现套利方向，就要把合约到期前的预期分红点数从基差中剥离。」（運算方向寫成「從基差中減去分紅點數」）
- 檢查員說原文是：原文的實際運算是把分紅點數「加回」觀察到的價差：含分紅價差 = 實際價差 + 分紅點數（IF1907：-24.14 + 35.33 = 11.19）。原文所謂「剝離了分紅影響後的真實基差」，指的是還原掉分紅對基差的擾動後的真實基差，數學上是加法而非減法；減法（-24.14 - 35.33 = -59.47）會把原文明確的「由貼水轉升水」結論完全反轉。
- 引文：「然而分红对IF1907的影响点数为35.33点,考虑了分红因素之后,合约的基差为11.19点,实质上处于升水状态」（1.4 最新分红预测结果）
- 引文在全文：找得到
- 人工判定：＿＿（真 / 誤報 / 吹毛求疵）
