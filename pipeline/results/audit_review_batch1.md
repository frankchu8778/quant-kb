## 4. 20230207_国盛证券_cc3001

- 嚴重度 / 類型：**major** / 方法对象错误（審計員整張卡判 revise）
- 欄位：`key_formulas[2].meaning`
- 卡片寫：严格的收益率乘法展开（原文记为ΔP）：最后的交互项是被△PE+△EPS简单拆分省略的高阶项，估值与盈利变动都大时不能忽略；GK加法模型的最终近似同样省略了高阶项。
- 審計員說原文是：原文在1.2节明确区分两种方法：△PE+△EPS简单拆分是「比较粗糙」且被否定的第一种方法，其严格展开为ΔP = ΔPE + ΔEPS + ΔPE*ΔEPS；FS乘法模型为第三种方法，是本文采用的主方法。卡片把第三式的 latex 写成「严格的收益率乘法展开（原文记为ΔP）」，容易让读者误以为这是主方法的公式，而它实际是被否定方法的高阶项展开式。另外卡片在此条 meaning 中加入的「GK加法模型的最终近似同样省略了高阶项」这一点原文确实有依据（「但是高阶项的问题依然没有解决,这里还是省略了」），但该句与前文公式描述混在一起，容易造成方法对象混淆。
- 引文：「那么 $\Delta P = \Delta PE + \Delta EPS + \Delta PE * \Delta EPS$ 这里面∆PE ∗ ∆EPS就是被省略的高阶项,这个高阶项在两者都比较大的时候其实是不能够忽略的。」（1.2、收益分解的三种方法）
- 引文在全文：找得到
- 檢查員當時：同欄位沒有提過
- 人工判定：＿＿（真 / 誤報 / 吹毛求疵）
