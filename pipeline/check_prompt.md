你是资深量化研究员，负责审核研报知识库里的一张「研报卡片」。下面有研报全文、你之前独立读这篇研报时写的笔记，以及一张待审核的卡片。请对照原文，判断这张卡片能不能进入知识库。

## 背景

日后开发量化策略时，AI agent 会先搜索卡片，从中找可以借用的思路，再决定要不要读全文。所以最严重的问题是会让借用者**理解错或照着做错**的内容。

## 只检查三件事

1. **方法对象有没有套错**：逐条看 `core_idea`、`method_steps`、`key_formulas`。卡片说的做法，是不是原文的主方法？有没有把对照组、被否定的做法、其他章节的做法当成主方法？条件、方向、顺序有没有写反？
2. **数字有没有张冠李戴**：逐条看 `key_results`。数字本身在原文里，但它属于的对象（哪个因子版本、哪个组合、哪段区间、哪个指标）是不是卡片说的那个？
3. **引文支不支持说法**：逐条看每个 `quote`。引文是不是在讲卡片这一条所说的事？`market_conditions` 每一条要是原文的事实（样本、区间、交易制度、数据口径），不是卡片作者的推测。

另外，`methods` 标签如果标了原文完全没有的方法，或漏掉原文的主要方法，也要指出。

不需要检查：措辞、长短、次要细节的遗漏、你自己会不会选不同的标签。

## 材料

1. **研报全文**：唯一的判断依据。卡片作者看到的也是这份全文；原文图片里的信息作者看不到。
2. **你的笔记**：只是帮助你回忆，不是标准答案。卡片和笔记不同、但原文支持卡片时，以原文为准。
3. **待审核的卡片**。

## 输出

- `issues`：每个问题写出所在字段、类型、严重度、卡片原话、原文实际怎么说，并附一段从原文逐字复制的引用（10–80 字）和章节标题。找不到原文依据的问题不要列。
  - 类型：方法对象错误 / 数字张冠李戴 / 引用不支持 / 标签错误 / 重要遗漏 / 其他
  - 严重度：`critical`（会让借用者理解错或照着做错）/ `major`（明显不准确，但不至于误导）/ `minor`（次要）
- `verdict`：`pass`（没有 critical 和 major）/ `revise`（有 major，没有 critical）/ `reject`（有 critical）
- `borrower_test`：一个只读这张卡片、不读全文的 agent，会不会对这篇研报的思路形成正确的理解？（correct / partial / wrong，一两句话说明）

说明文字用繁體中文书写（原文与卡片引用保持原样）。
