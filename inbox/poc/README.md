# POC 研報放這裡（20 篇）

直接把 PDF 丟進這個資料夾，檔名不用改。

## 挑選原則（盡量涵蓋差異，POC 才測得出問題）

| 類別 | 篇數 | 目的 |
|---|---|---|
| 多因子 / 因子構建（含大量公式） | 4 | 測公式轉錄、方法分類 |
| 擇時 / CTA / 趨勢 | 3 | 方法分類 |
| 機器學習 / 深度學習 | 3 | 測專有名詞、模型結構描述 |
| 組合優化 / 風險模型 | 2 | 測數學推導 |
| 另類數據 / 文本 / 事件驅動 | 2 | 測冷門方法分類 |
| 表格很多、多欄排版很亂的 | 2 | 測 MinerU 解析 |
| 很長的深度報告（>50 頁） | 2 | 測長 context |
| 很短的點評 / 週報類 | 1 | 測「低價值研報」能否被正確標記 |
| 掃描版 / 圖片型 PDF（如果有） | 1 | 測 OCR |

湊不齊某類就用其他類補，總數 20 即可。
